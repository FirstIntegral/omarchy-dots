# Machine map — apps on this box

Per-machine documentation, like `hypr/monitors.lua`. **Not** part of the apply pack:
`apply.sh` / `sync.sh` never touch these files, and nothing here lands on a destination
box. This is the "what is installed and why" map for the source machine.

Keep it current when you install, remove, or re-source an app (add a line here in the
same turn, regenerate the lists, commit).

## Package lists (`packages/`)

Regenerated by hand, machine-readable:

```sh
pacman -Qqen > packages/pkglist-pacman.txt   # explicit, native + omarchy repo
pacman -Qqm  > packages/pkglist-aur.txt      # foreign (AUR); has been empty so far
flatpak list --app --columns=application > packages/pkglist-flatpak.txt
```

Note: this machine has **no foreign packages** (`pacman -Qm` is empty). AUR-ish tools
(yay, mise-bin, grok-bot, herdr, …) come from the distro's own `omarchy` repo, so they
show up in `pkglist-pacman.txt`. Install new software from `extra`/`omarchy` when it
exists there; AUR only when it doesn't.

## App map

| App | Source | Why | Quirks |
|-----|--------|-----|--------|
| tor-browser-launcher | `extra` (0.3.9) | Tor Browser downloader/verifier/launcher | Must run **native**, not flatpak: flatpak's seccomp blocks nested user namespaces, so Tor Browser falls back to a degraded sandbox and warns "security features may offer less protection". Host userns works (`kernel.unprivileged_userns_clone = 1`, no AppArmor). Browser lives in `~/.local/share/torbrowser/`, GPG homedir `~/.local/share/torbrowser/gnupg_homedir/`. |
| tor | `extra` | dependency of tor-browser-launcher | No service enabled; not used by the browser itself (browser bundles its own tor). `torsocks` optional if CLI needs SOCKS via 127.0.0.1:9050. |
| flatpak | `extra` | sandboxed GUI apps | Only app installed: `com.nvidia.geforcenow`. Prefer native pacman over flatpak for anything Tor/network-browser-shaped. |
| nvidia-open-dkms | `omarchy` | NVIDIA driver (DKMS) | See README hard rules for kernel/hook specifics. |
| proton-vpn-gtk-app | `extra` | ProtonVPN client | Bundles `proton-vpn-daemon` + python CLI stack. |
| yay | `omarchy` repo | AUR helper | Only needed if a package genuinely lives outside `extra`/`omarchy`. |
| agentic-OpenTabletDriver | `~/Projects/agentic-OpenTabletDriver` (build from source) | pen tablet fork | Never the stock `opentabletdriver` package — see README hard rules. |

## Install quirks log (chronological)

- **2026-10-03 — Tor Browser via flatpak shows security warning.** Cause: nested
  user-namespace creation blocked inside flatpak sandbox (`unshare -Ur` → EPERM inside
  the sandbox, works on host). Fix: native `torbrowser-launcher`. Package was built
  from AUR PKGBUILD first, then re-installed from `extra` (same 0.3.9-1) once we noticed
  it had been promoted; `pacman -Qm` confirms zero foreign packages.
- **2026-10-03 — expac `%r` misleads on this box.** `expac -Q '%r %n'` reports every
  package as `local`. Do not use it to generate the AUR list; use `pacman -Qqm`.
